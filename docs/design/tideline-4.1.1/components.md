# Components

Every component the Tideline 4.1.1 canvases use, plus the 4.1.1 system
components the contract names. Generated on 27 November 2026 from the system
artifact's `project/components/index.d.ts` (props) and a scan of every
non-"Current", non-"Superseded" board on the five design canvases for
`Duna.<Name>` references.

- **Canvases** column: `Web` website, `HQ`, `PN` Player native, `PW` Player
  web, `Pro`; the number is how many proposed boards use it, then up to three
  board names (`project/<Board>.dc.html`). "system only" means the component is
  specified in the system artifact but no board renders it yet.
- **In index.d.ts**: whether the system artifact declares it. "no" means a
  board uses a name the artifact does not type (2.x leftovers); build it from
  the board or use the listed replacement.
- Props are the ones that matter (styling escape hatches omitted); `a/b/c`
  lists allowed literal values. The system card
  (`project/components/<Name>/README.md`, `preview.html`) is the full spec.
- Rules from the contract apply to all of them: tokens only, Solar only for
  live, 14/16/20/24 icon scale, chips contain their content, Rise / Rally /
  Cross, reduced motion, 44 pt targets (48 web), keyboard and screen-reader
  names. Native builds use the same names and props with native behaviour
  (see the artifact's `project/ui-sdk.md`).
- Rename rules: the logo is `DunaMark` / `DunaLogo`; `Crest` / `CrestAt` are
  club crests (prefer `ClubMark`). `FormDots` → `FormCrests`, `LivePulse` →
  `LiveCrest`, `Score` → `NetScore`, `TimeSlotGrid` → `TimeSlots`,
  `TopProgress` → `HorizonSweep`; old names keep working for one release.
- Native tab bars use the system tab bar (contract R20); `TabBar` is the web
  component.
