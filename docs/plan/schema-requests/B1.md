# Schema request: B1 (club setup)

Requested by B1 for the next schema-steward wave. Additive only; nothing in
the frozen contract changes. Until it lands the service works without them
(noted in `docs/product/club-setup.md`).

## `setup_run_pages`

| Column           | Type          | Null | Default | Why                                                                                                                                                                                    |
| ---------------- | ------------- | ---- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `content_hash`   | `varchar(64)` | yes  | –       | SHA-256 of the page text as read. Lets a re-read skip a page whose text did not change (no model call) and shows two addresses serving the same page. The text itself is never stored. |
| `failure_reason` | `varchar(64)` | yes  | –       | Why one page failed (same values as `setup_runs.failure_reason`), so CS-Reading can say "blocked" or "too large" per page instead of only "failed".                                    |
| `updated_at`     | `timestamptz` | no   | `now()` | Heartbeat per page; today the run's `updated_at` is the lease.                                                                                                                         |

## `setup_runs`

| Column        | Type          | Null | Default | Why                                                                                                                                    |
| ------------- | ------------- | ---- | ------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `lease_until` | `timestamptz` | yes  | –       | An explicit step lease. Today `updated_at` doubles as the heartbeat and is set back when a step hands the run over, which reads oddly. |
| `chars_read`  | `integer`     | no   | `0`     | Total text read, so the per-run byte cap is enforced across steps (today: pages × per-page cap).                                       |
