# Follow-up drops, renames and type changes after W3-0

Migration 0116 (W3-0) is additive only: the HQ production build applies
migrations before the web app redeploys, so a drop or rename would break the
running site for a few minutes. Every removal below waits until the package
that owns the code has stopped reading the old shape and that change is live.
The package that removes the code writes the request in
`docs/plan/schema-requests/<WP>.md`; the next wave's schema steward generates
the drop.

Not a drop, but a default to change when its owner is ready: `organization_money_settings.payout_interval` defaults to `weekly`; payout-policy §3
makes `daily` the default. Changing a column default is an `ALTER COLUMN`,
which 0116 avoids; B2 sets `daily` when it creates the row and asks the next
steward for the default change.
