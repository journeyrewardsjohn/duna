# Duna typography

- Fellix is the core product typeface for body copy, controls, labels, metadata,
  numeric data, and native app text.
- Archivo is reserved for web H1 and H2 display headings.
- Product text must never render below 10px (0.625rem). Run
  `pnpm verify:readable-type` before shipping typography changes.

The Fellix font files in this repository are proprietary licensed assets supplied
by Journey Rewards Inc. They must not be copied into public source distributions
or reused outside the licensed Duna product.
